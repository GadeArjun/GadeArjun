## 🚀 Featured Projects

### 🎯 SlideAI — AI PowerPoint Presentation Generator
> **The most architecturally ambitious project in this portfolio — a full agentic generation pipeline.**

[![Live](https://img.shields.io/badge/🌐%20Live%20Demo-slideai--h19h.onrender.com-7c3aed?style=flat-square)](https://slideai-h19h.onrender.com/)
[![Repo](https://img.shields.io/badge/GitHub-SlideAI-181717?style=flat-square&logo=github)](https://github.com/GadeArjun/SlideAI)
![JS](https://img.shields.io/badge/JavaScript-98.1%25-F7DF1E?style=flat-square&logo=javascript)

An **AI-driven MERN platform** that converts a single text prompt into a fully designed, editable PowerPoint presentation via a multi-stage agentic pipeline: `Intent Extraction → Slide Planning → Code Generation → Rendering`.

**What makes it technically interesting:**
- Real-time per-slide progress streamed over **Socket.IO** — 12 distinct events (`planner:slide:status`, `coder:complete`, `project:completed`, etc.), with pause/resume support
- Modern frontend stack: React 18 + Vite + **Zustand** + **TanStack Query v5** + **React Hook Form + Zod** validation
- Modular backend architecture: `agents/ → pipeline/ → services/ → controllers/` — a genuinely clean separation of concerns
- JWT-authenticated, MongoDB-persisted user projects with a cinematic dark-themed editor UI

**Stack:** `Node.js` `Express` `MongoDB` `React 18 + Vite` `Socket.IO` `Zustand` `TanStack Query` `Framer Motion` `JWT`

### 📹 MeetFlow — Real-Time Video Meeting Platform
> **Production-deployed video conferencing built from scratch, Zoom-style.**

[![Live](https://img.shields.io/badge/🌐%20Live%20Demo-meetflow--3mv5.onrender.com-7c3aed?style=flat-square)](https://meetflow-3mv5.onrender.com/)

![CSS](https://img.shields.io/badge/CSS-35.7%25-1572B6?style=flat-square&logo=css3)

A full-featured **Zoom-like meeting platform** with peer-to-peer video/audio, live chat, participant management, and meeting scheduling.

**Technical highlights:**
- Full **WebRTC** signaling: offer/answer/ICE candidate exchange over Socket.IO

- RESTful API spanning users, meetings, and analytics

**Stack:** `React` `Vite` `Node.js` `Express` `MongoDB` `WebRTC` `Socket.IO` `JWT` `Cloudinary` `Nodemailer`

### 🟣 NebulaChat — Anonymous Real-Time Chat Platform
> **Privacy-first ephemeral messaging. Zero database. Zero tracking.**

[![Live](https://img.shields.io/badge/🌐%20Live%20Demo-nebulachat.onrender.com-7c3aed?style=flat-square)](https://nebulachat.onrender.com/)
[![Repo](https://img.shields.io/badge/GitHub-Nebulachat-181717?style=flat-square&logo=github)](https://github.com/GadeArjun/Nebulachat)
![JS](https://img.shields.io/badge/JavaScript-94.9%25-F7DF1E?style=flat-square&logo=javascript)

A **Next.js + Socket.IO** anonymous chat app built on a simple rule: no auth, no storage, no logs. Messages exist only in memory — gone when the tab closes.

**Design choices that stand out:**
- **PWA-ready**: manifest, icon set, and offline-capable structure
- **Framer Motion** animations throughout for a polished, app-like feel
- Notification sounds for incoming messages
- Express + Socket.IO server integrated directly inside the Next.js app — no separate backend service

**Stack:** `Next.js` `React` `Socket.IO` `Express` `Tailwind CSS` `Framer Motion`

### 💼 MarketMint — AI Lead-Discovery Platform for Agencies & Freelancers
> **A complete SaaS-style product: marketing site, auth, dashboard, and a real scoring engine.**

[![Live](https://img.shields.io/badge/🌐%20Live%20Demo-marketmint--vert.vercel.app-7c3aed?style=flat-square)](https://marketmint-vert.vercel.app/)
[![Repo](https://img.shields.io/badge/GitHub-market--mint-181717?style=flat-square&logo=github)](https://github.com/GadeArjun/market-mint)
![JS](https://img.shields.io/badge/JavaScript-96.7%25-F7DF1E?style=flat-square&logo=javascript)
⭐ 1 star

Helps agencies and freelancers discover real local businesses by category and location, audit their digital presence, score the opportunity, and generate ready-to-send outreach messages.

**What's under the hood:**
- Discovery pipeline: geocode location → find nearby businesses → enrich with website/social/contact signals → rank by opportunity gap → generate outreach message packs (WhatsApp, email, DM)
- Full product surface: marketing landing page, JWT auth, protected dashboard, paginated search history, analytics (trends, top categories, priority distribution), and a credits/plan system (Free/Starter/Pro/Agency)
- Backend built on Express 5 with `cheerio` for scraping, `helmet`/`compression`/`morgan` for production hardening

**Stack:** `React 18` `Vite` `Node.js` `Express 5` `MongoDB` `Tailwind CSS` `Cheerio` `Recharts` `JWT`

### 📚 Library Management System — Python Desktop App with Telegram Alerts
> **Desktop GUI + bot integration. A practical, thoughtful utility.**

[![Repo](https://img.shields.io/badge/GitHub-Library--Management--System-181717?style=flat-square&logo=github)](https://github.com/GadeArjun/Library-Management-System)
![Python](https://img.shields.io/badge/Python-100%25-3776AB?style=flat-square&logo=python)

A **Tkinter + SQLite** desktop app for managing books, student borrow records, and automated return reminders — with **Telegram bot notifications** as due dates approach.

**What's clever about it:**
- Auto-calculates a 15-day return window and tracks remaining days dynamically per record
- Sends **Telegram messages** (via Telethon) directly to students 2 days before their due date
- Offline-first: pure SQLite, no internet dependency for core operations
- Clean two-table schema: `BookData` + `studentData`

**Stack:** `Python` `Tkinter` `SQLite` `Telethon` `Telegram API` `Requests`
