## 🚀 Featured Projects

### 🎯 SlideAI — AI PowerPoint Presentation Generator
> **The most architecturally ambitious project in this portfolio.**

[![Live](https://img.shields.io/badge/🌐%20Live%20Demo-slideai--h19h.onrender.com-7c3aed?style=flat-square)](https://slideai-h19h.onrender.com/)
[![Repo](https://img.shields.io/badge/GitHub-SlideAI-181717?style=flat-square&logo=github)](https://github.com/GadeArjun/SlideAI)
![JS](https://img.shields.io/badge/JavaScript-98.1%25-F7DF1E?style=flat-square&logo=javascript)

An **AI-driven MERN platform** that converts a single text prompt into a fully designed PowerPoint presentation via a multi-stage agentic pipeline.

**What makes it technically interesting:**
- Custom AI pipeline: `Intent Extraction → Slide Planning → Code Generation → Rendering`
- Real-time per-slide progress broadcast via **Socket.IO** (pause/resume support)
- Modern frontend stack: React 18 + Vite + **Zustand** + **TanStack Query v5** + **Zod** validation
- Modular backend: agents → pipeline → services → controllers — a genuinely clean architecture

**Stack:** `Node.js` `Express` `MongoDB` `React` `Socket.IO` `Framer Motion` `JWT` `Zustand`

### 📹 MeetFlow — Real-Time Video Meeting Platform
> **Production-deployed video conferencing built from scratch.**

[![Live](https://img.shields.io/badge/🌐%20Live%20Demo-meetflow--3mv5.onrender.com-7c3aed?style=flat-square)](https://meetflow-3mv5.onrender.com/)
[![Repo](https://img.shields.io/badge/GitHub-MeetFlow-181717?style=flat-square&logo=github)](https://github.com/GadeArjun/MeetFlow)
![JS](https://img.shields.io/badge/JavaScript-62.8%25-F7DF1E?style=flat-square&logo=javascript)

A full-featured **Zoom-like meeting platform** with P2P video/audio, live chat, participant management, and meeting scheduling — all from the ground up.

**Technical highlights:**
- Full **WebRTC** signaling: offer/answer/ICE candidate exchange over Socket.IO
- 7 custom socket events: camera/mic/screen toggle, participant sync, real-time messaging
- Complete user auth: JWT + bcrypt + Cloudinary avatar uploads + password reset via email
- Branded **HTML email invitations** with Nodemailer
- RESTful API: 12+ endpoints covering users, meetings, and analytics

**Stack:** `React` `Node.js` `MongoDB` `WebRTC` `Socket.IO` `JWT` `Cloudinary` `Nodemailer`

### 🟣 NebulaChat — Anonymous Real-Time Chat Platform
> **Privacy-first ephemeral messaging. Zero database. Zero tracking.**

[![Live](https://img.shields.io/badge/🌐%20Live%20Demo-nebulachat.onrender.com-7c3aed?style=flat-square)](https://nebulachat.onrender.com/)
[![Repo](https://img.shields.io/badge/GitHub-Nebulachat-181717?style=flat-square&logo=github)](https://github.com/GadeArjun/Nebulachat)
![JS](https://img.shields.io/badge/JavaScript-94.9%25-F7DF1E?style=flat-square&logo=javascript)

A **Next.js + Socket.IO** anonymous chat app with a philosophy: no auth, no storage, no logs. Messages exist only in memory — gone when you close the tab.

**Design choices that stand out:**
- **PWA-ready**: manifest, icons, offline-capable structure
- **Framer Motion** animations throughout for a polished, app-like feel
- Notification sounds for incoming messages
- Server-side Express + Socket.IO integrated inside the Next.js project — not a separate backend

**Stack:** `Next.js` `React` `Socket.IO` `Express` `Tailwind CSS` `Framer Motion`

### 📚 Library Management System — Python Desktop App with Telegram Alerts
> **Desktop GUI + bot integration. A practical, thoughtful utility.**

[![Repo](https://img.shields.io/badge/GitHub-Library--Management--System-181717?style=flat-square&logo=github)](https://github.com/GadeArjun/Library-Management-System)
![Python](https://img.shields.io/badge/Python-100%25-3776AB?style=flat-square&logo=python)

A **Tkinter + SQLite** desktop app for managing books, student borrow records, and automated return reminders — with **Telegram bot notifications** when due dates approach.

**What's clever about it:**
- Auto-calculates 15-day return windows and remaining days dynamically
- Sends **Telegram messages** (via Telethon) directly to students' phone numbers 2 days before due date
- Offline-first: pure SQLite, no internet dependency for core operations
- Clean 2-table schema: `BookData` + `studentData`

**Stack:** `Python` `Tkinter` `SQLite` `Telethon` `Telegram API` `Requests`
